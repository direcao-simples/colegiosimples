Questões da prova
➕ Adicionar questão

Ou importe várias de uma vez: envie um arquivo JSON (formato padrão, igual ao contrato do Radix) ou cole no campo abaixo. A plataforma confere, salva na prova, exporta o caderno padronizado e usa o gabarito na correção automática.

[
  {
    "numero": 1,
    "area": "Linguagens",
    "contexto": "Texto de apoio (opcional).",
    "fonte": "ENEM 2023 (adaptada) — opcional",
    "pergunta": "O comando da questão.",
    "alternativas": { "A": "…", "B": "…", "C": "…", "D": "…", "E": "…" },
    "gabarito": "C"
  }
]

Também aceita o formato de texto simples (1. enunciado / A)…E) / Gabarito: X) — o contrato completo está em _acesso_simples_contrato_questoes.md na pasta do site.
